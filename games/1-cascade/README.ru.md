# CASCADE

**[English version](README.md)** · [Все проекты](../../README.ru.md)

Путешествие от первого лица через вулканическую катастрофу: от причала к белой деревне на скале и маяку, пока на другой стороне кальдеры извергается вулкан, обрушивается его склон, море отступает и стена воды пересекает бухту. Вы наблюдатель; никто на вас не нападает.

Проект создан с помощью **Fable 5.2** на Unity 6000.6.0f1 и HDRP 17.6. Геометрия, шейдеры и звук генерируются кодом. Фототекстуры Poly Haven распространяются по CC0; см. [авторы и источники](CREDITS.ru.md).

## Запуск

Дважды щёлкните **`PLAY.bat`** в этой папке. Устанавливать Unity не нужно. Лаунчер запускает `Builds/CASCADE/CASCADE.exe` с профилем полного качества.

Полное прохождение занимает около **11 минут**. Рекомендуются наушники.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | Осмотреться |
| W / S | Идти по маршруту / немного отступить |
| A / D | Двигаться в стороны в пределах маршрута |
| Shift | Идти быстрее |
| C | Включить или выключить автоматический кинематографичный режим |
| Esc | Пауза; Esc или Enter — продолжить, Q — выйти |
| F11 | Переключить полноэкранный режим |

Для записи без ручного управления нажмите **C** сразу после появления названия.

## Открыть и пересобрать в Unity

1. Добавьте эту папку в Unity Hub, используя **Unity 6000.6.0f1**.
2. Откройте `Assets/_Game/Scenes/Main.unity` и нажмите **Play** или
3. Выберите **Tools → CASCADE → Rebuild All**, чтобы заново создать ресурсы и сцену.
