# CASCADE

**[Русская версия](README.ru.md)** · [All projects](../../README.md)

A first-person walk through a volcanic catastrophe: from a harbour quay to a white cliff village and its lighthouse while a volcano erupts across the caldera, its flank collapses, the sea draws back and a wall of water crosses the bay. You are an observer; nothing attacks you.

Created with **Fable 5.2** using Unity 6000.6.0f1 and HDRP 17.6. Geometry, shaders and sound are generated by code. Photo textures come from Poly Haven under CC0; see [credits](CREDITS.en.md).

## Play

Double-click **`PLAY.bat`** in this folder. No Unity installation is required. The launcher starts `Builds/CASCADE/CASCADE.exe` with the full-quality profile.

The full experience takes about **11 minutes**. Headphones are recommended.

## Controls

| Key | Action |
|---|---|
| Mouse | Look around |
| W / S | Walk along the path / step back |
| A / D | Move sideways within the path |
| Shift | Walk faster |
| C | Toggle hands-free cinematic mode |
| Esc | Pause; use Esc or Enter to resume and Q to quit |
| F11 | Toggle fullscreen |

For a hands-free recording, press **C** immediately after the title.

## Open and rebuild in Unity

1. Add this folder to Unity Hub using **Unity 6000.6.0f1**.
2. Open `Assets/_Game/Scenes/Main.unity` and press **Play**, or
3. Choose **Tools → CASCADE → Rebuild All** to regenerate assets and the scene.
