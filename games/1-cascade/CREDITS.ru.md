# CASCADE — сторонние материалы и авторы

**[English version](CREDITS.en.md)** · [README проекта](README.ru.md)

Вся геометрия, шейдеры, частицы, звук и текстуры, не перечисленные ниже, генерируются кодом этого проекта.

## Фототекстуры — Poly Haven (CC0)

Физически корректные текстуры поверхностей взяты с сайта [Poly Haven](https://polyhaven.com) и распространяются по [общественному достоянию CC0 1.0](https://polyhaven.com/license). Указание авторства не обязательно, но здесь оно приводится с благодарностью.

| Ресурс | Назначение |
|---|---|
| painted_plaster_wall | Белёные стены, штукатурные элементы и окрашенные синие купола |
| white_plaster_02 | Состаренная побелка и мокрые стены после волны |
| grey_stone_path | Набережная, причал и мощение лестниц |
| large_sandstone_blocks | Окрашенная кладка из пемзы |
| old_stone_wall | Сухие каменные стены и руины |
| dark_rock, cliff_side, rock_face_03, dry_ground_rocks | Слои скал кальдеры |
| low_tide_rocks, brown_mud_02, damp_beach_sand, dark_rock_02 | Морское дно, обнажившееся после отлива |
| rocks_ground_02, dark_rock_02, rocky_gravel | Вулканический пепел, лавовый камень и красная скория |
| gravel_floor_02 | Тропа на мысу |
| wood_planks_grey | Окрашенные двери, ставни, лодки и деревянные элементы |

## Сгенерированные текстуры

Карта наклонов поверхности океана, рисунок пены, шум облака извержения и другие процедурные карты создаются кодом проекта.
