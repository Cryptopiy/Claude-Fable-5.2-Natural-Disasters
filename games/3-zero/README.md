# ZERO

**[Русская версия](README.ru.md)** · [All projects](../../README.md)

You are a passenger in the left window seat of an airliner at 11.5 km altitude. A star appears in the daytime sky and remains fixed in the window: it is a 26 km asteroid approaching impact 260 km away. Watch it fall, strike the ground and grow into a planetary-scale explosion until the blast wave reaches the aircraft.

Created with **Fable 5.2** using Unity 6000.6.0f1 and URP 17.6. Geometry, shaders, particles and sound are procedural. No combat, no HUD; the complete experience takes about **11 minutes**.

## Play

Double-click **`PLAY.bat`** in this folder. No Unity installation is required. The launcher starts `Builds/ZERO/ZERO.exe` with the full-quality profile.

Headphones are recommended. To record the experience hands-free, press **C** once after launch.

## Controls

| Key | Action |
|---|---|
| Mouse | Look around; the head follows to keep the view near the window |
| W / S | Lean toward the glass / sit back |
| Shift or right mouse button | Look closer |
| C | Toggle hands-free cinematic mode |
| Esc | Pause; Q quits |
| F11 | Toggle fullscreen |

## Open and rebuild in Unity

1. Add this folder to Unity Hub using **Unity 6000.6.0f1**.
2. Open `Assets/_Game/Scenes/Main.unity` and press **Play**, or
3. Choose **Tools → ZERO → Rebuild All** to regenerate assets and the scene.

All geometry, shaders, particles, sound and other visual content are generated by the project; no third-party photo textures are used.
