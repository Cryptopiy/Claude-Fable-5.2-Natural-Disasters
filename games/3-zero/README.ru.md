# ZERO

**[English version](README.md)** · [Все проекты](../../README.ru.md)

Вы пассажир у левого иллюминатора авиалайнера на высоте 11,5 км. В дневном небе появляется звезда и остаётся неподвижной в окне: это астероид длиной 26 км, который упадёт в 260 км от вас. Наблюдайте за падением, ударом о землю и ростом взрыва до планетарного масштаба, пока ударная волна не достигнет самолёта.

Проект создан с помощью **Fable 5.2** на Unity 6000.6.0f1 и URP 17.6. Геометрия, шейдеры, частицы и звук создаются процедурно. Здесь нет боя и интерфейса; полное переживание длится около **11 минут**.

## Запуск

Дважды щёлкните **`PLAY.bat`** в этой папке. Устанавливать Unity не нужно. Лаунчер запускает `Builds/ZERO/ZERO.exe` с профилем полного качества.

Рекомендуются наушники. Для записи без ручного управления нажмите **C** один раз после запуска.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | Осмотреться; голова следует за взглядом, сохраняя вид у иллюминатора |
| W / S | Наклониться к стеклу / отклониться назад |
| Shift или правая кнопка мыши | Приблизить вид |
| C | Включить или выключить автоматический кинематографичный режим |
| Esc | Пауза; Q — выход |
| F11 | Переключить полноэкранный режим |

## Открыть и пересобрать в Unity

1. Добавьте эту папку в Unity Hub, используя **Unity 6000.6.0f1**.
2. Откройте `Assets/_Game/Scenes/Main.unity` и нажмите **Play** или
3. Выберите **Tools → ZERO → Rebuild All**, чтобы заново создать ресурсы и сцену.

Вся геометрия, шейдеры, частицы, звук и остальное визуальное содержимое генерируются проектом; сторонние фототекстуры не используются.
