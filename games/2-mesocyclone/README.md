# MESOCYCLONE

**[Русская версия](README.ru.md)** · [All projects](../../README.md)

An eleven-minute first-person ride across the Great Plains. A self-driving pickup travels north toward a huge supercell: a shelf cloud, hail cracking the windscreen, a wedge tornado revealed by lightning, then stars and a lit canopy. You watch; the storm does not care.

Created with **Fable 5.2** using Unity 6000.6.0f1 and HDRP 17.6. Geometry, shaders, particles and sound are generated by code. Photo textures come from Poly Haven under CC0; see [credits](CREDITS.en.md).

## Play

Double-click **`PLAY.bat`** in this folder. No Unity installation is required. The launcher starts `Builds/MESOCYCLONE/MESOCYCLONE.exe` with the full-quality profile.

The full ride takes about **11 minutes**. Headphones are recommended. **This project contains lightning flashes.**

## Controls

| Key | Action |
|---|---|
| Mouse | Look around; the cab limits the view |
| W / S | Increase / decrease speed |
| Shift | Hold for the intended cinematic speed |
| C | Toggle hands-free cinematic mode |
| Esc | Pause |
| F11 | Toggle fullscreen |

## Open and rebuild in Unity

1. Add this folder to Unity Hub using **Unity 6000.6.0f1**.
2. Open `Assets/_Game/Scenes/Main.unity` and press **Play**, or
3. Choose **Tools → MESOCYCLONE → Rebuild All** to regenerate assets and the scene.
