Одиннадцатиминутная поездка от первого лица по Великим равнинам. Самоуправляемый пикап едет на север навстречу огромной суперъячейке: полка облаков, град, раскалывающий лобовое стекло, клиновидный торнадо, видимый во вспышках молний, а затем звёзды и освещённый навес. Вы наблюдаете; буре нет до вас дела.

Проект создан с помощью **Fable 5.2** на Unity 6000.6.0f1 и HDRP 17.6. Геометрия, шейдеры, частицы и звук генерируются кодом. Фототекстуры Poly Haven распространяются по CC0; см. [авторы и источники](CREDITS.ru.md).

## Запуск

Дважды щёлкните **`PLAY.bat`** в этой папке. Устанавливать Unity не нужно. Лаунчер запускает `Builds/MESOCYCLONE/MESOCYCLONE.exe` с профилем полного качества.

Полная поездка занимает около **11 минут**. Рекомендуются наушники. **В проекте есть вспышки молний.**

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | Осмотреться; обзор ограничен кабиной |
| W / S | Увеличить / уменьшить скорость |
| Shift | Удерживайте для скорости, задуманной для кинематографичного режима |
| C | Включить или выключить автоматический кинематографичный режим |
| Esc | Пауза |
| F11 | Переключить полноэкранный режим |

## Открыть и пересобрать в Unity

1. Добавьте эту папку в Unity Hub, используя **Unity 6000.6.0f1**.
2. Откройте `Assets/_Game/Scenes/Main.unity` и нажмите **Play** или
3. Выберите **Tools → MESOCYCLONE → Rebuild All**, чтобы заново создать ресурсы и сцену.
